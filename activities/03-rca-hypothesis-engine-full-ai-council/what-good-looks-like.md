**Expected output structure**
A strong AI output for this activity will contain the following sections / elements:
- Three independent registers (one per tool), each with 5 hypotheses in the fixed structure
- Consensus scorecard showing agreement per hypothesis (STRONG / WEAK / DIVERGENT / CONFLICT)
- Red Team challenge identifying: shared assumption, ignored evidence, alternative, falsification test, revised confidence
- Final executive recommendation: APPROVE / HOLD / RUN TEST FIRST
**Scoring rubric (5 dimensions)**
**Common failure modes — watch for these**
- An analyst collapses to a single confident answer. Response: 'the output must be a 5-hypothesis register. Re-generate.'
- Hypotheses are vague ('something with authentication'). Response: 'name specific system, time, mechanism'.
- Red Team is sycophantic ('all three analyses are strong'). Response: 'be adversarial — identify a specific assumption all three made without evidence'.
**Debrief question for the room**
Where did the AI add the most value — and where would you NOT trust it without a human review step? Be specific about the failure mode you saw.
Scoring is a facilitation device — not an exam. The point is to make the quality dimensions visible and discussable, so participants internalize what a 'good' AI output looks like for their own work.
