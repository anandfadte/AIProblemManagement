**Expected output structure**
A strong AI output for this activity will contain the following sections / elements:
- Team-level attrition table with Regretted_% and evidence-cited causes
- 3-paragraph CPO narrative with explicit compensation-vs-manager trade-off
- 'What I had to assume' section (short — 2-3 bullets)
- Single defensible recommendation tied to specific data columns
**Scoring rubric (5 dimensions)**
**Common failure modes — watch for these**
- Models converge on 'compensation' as the answer because exit interviews over-report it (self-serving reason). The Red Team should catch this; if it doesn't, re-prompt with explicit disconfirmer framing.
- Analyst recommends 'do both programs' — ignores the CFO's explicit one-or-the-other constraint. Challenge immediately in debrief.
- Confidence is reported as 'High' on a dataset of 450 exits with heavy self-report bias in the Primary_Reason column. 'High' is almost always wrong here; 'Medium with the following reservations' is the mature answer.
**Debrief question for the room**
Where did the AI add the most value — and where would you NOT trust it without a human review step? Be specific about the failure mode you saw.
Scoring is a facilitation device — not an exam. The point is to make the quality dimensions visible and discussable, so participants internalize what a 'good' AI output looks like for their own work.
