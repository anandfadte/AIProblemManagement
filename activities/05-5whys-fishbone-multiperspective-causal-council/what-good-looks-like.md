**Expected output structure**
A strong AI output for this activity will contain the following sections / elements:
- Three distinct 5-Why chains from different starting points
- Fishbone with 7 categories populated (2-3 branches each)
- Testable vs. Speculative sort with specific test per TESTABLE branch
- Red Team: cross-analyst testability ranking (which branch has the HIGHEST signal:effort ratio)
- Recommended first branch to pursue
**Scoring rubric (5 dimensions)**
**Common failure modes — watch for these**
- Three chains are three rewrites of the same chain. Response: 're-prompt specifying start chain 2 from the vendor angle and chain 3 from the SLA tightening angle'.
- Branches are generic ('scheduling issues'). Response: 'cite the specific line from the narrative that supports this branch'.
- Testability sort labels obvious-blame branches as TESTABLE. Response: 'how would you prove the analyst was distracted on 14 July? If there is no evidence, it is SPECULATIVE'.
**Debrief question for the room**
Where did the AI add the most value — and where would you NOT trust it without a human review step? Be specific about the failure mode you saw.
Scoring is a facilitation device — not an exam. The point is to make the quality dimensions visible and discussable, so participants internalize what a 'good' AI output looks like for their own work.
