**Expected output structure**
A strong AI output for this activity will contain the following sections / elements:
- Working interactive React Artifact — URL + screenshot
- 6-8 views: stat tiles, Pareto, donut, trend line, app breakdown, drill-down
- 5+ filters that combine correctly
- AI-clustering labeled as derived (not source data)
- Executive can click through all filter combinations in <2 minutes
**Scoring rubric (5 dimensions)**
**Common failure modes — watch for these**
- First-pass dashboard is cluttered. Response: ask Claude to 'simplify — the executive wants to see 3 answers in 30 seconds'.
- Filters do not combine. Response: ask Claude to 'fix the filter logic — all filters must apply simultaneously'.
- Drill-down shows only aggregates. Response: ask Claude to 'drill-down must show specific incident IDs with descriptions'.
**Debrief question for the room**
Where did the AI add the most value — and where would you NOT trust it without a human review step? Be specific about the failure mode you saw.
Scoring is a facilitation device — not an exam. The point is to make the quality dimensions visible and discussable, so participants internalize what a 'good' AI output looks like for their own work.
