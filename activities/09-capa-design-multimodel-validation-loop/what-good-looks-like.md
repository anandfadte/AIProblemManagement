**Expected output structure**
A strong AI output for this activity will contain the following sections / elements:
- Claude draft CAPA with 5-classification coverage (per the skill)
- ChatGPT audit: specific completeness gaps identified
- Gemini pattern audit: specific prior-CAPA patterns worth applying
- Final CAB-ready matrix (Mistral synthesis) with all gaps closed
- Audit trail: which model contributed which action/correction
**Scoring rubric (5 dimensions)**
**Common failure modes — watch for these**
- Claude draft has only corrective actions. Response: ChatGPT audit will catch — proceed and let the loop work.
- Gemini's pattern audit is cursory. Response: 'read the specific prior CAPA for shadow IT — what verification method did it use? Apply same pattern here.'
- Mistral's final matrix loses one of the ChatGPT or Gemini additions. Response: 'the final matrix must integrate ALL three analysts' finds. Re-run.'
**Debrief question for the room**
Where did the AI add the most value — and where would you NOT trust it without a human review step? Be specific about the failure mode you saw.
Scoring is a facilitation device — not an exam. The point is to make the quality dimensions visible and discussable, so participants internalize what a 'good' AI output looks like for their own work.
