**Expected output structure**
A strong AI output for this activity will contain the following sections / elements:
- ChatGPT: top-10 variance-breach table + 2-account 9-month series + Known_Notes surfaced
- Gemini: 150-word visual read + explicit confidence statement
- Claude: causal chain diagram + per-account control gap + recommended CAPA
- Mistral: 1-page CFO brief with BLUF, 3 paragraphs, no padding
**Scoring rubric (5 dimensions)**
**Common failure modes — watch for these**
- Tools blur roles — ChatGPT starts speculating on causes, Mistral starts adding facts. Enforce role boundaries by re-prompting.
- Gemini confirms ChatGPT because it is told to; the independent read becomes a rubber stamp. Prompt Gemini WITHOUT giving it ChatGPT's output first.
- Claude's RCA is causally plausible but not anchored to the framework document. Audit will reject. Re-prompt with 'cite the framework section' instruction.
**Debrief question for the room**
Where did the AI add the most value — and where would you NOT trust it without a human review step? Be specific about the failure mode you saw.
Scoring is a facilitation device — not an exam. The point is to make the quality dimensions visible and discussable, so participants internalize what a 'good' AI output looks like for their own work.
